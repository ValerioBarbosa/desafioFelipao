# Desafios de Lógica em JavaScript

Coleção de desafios práticos desenvolvidos para exercitar fundamentos de programação e orientação a objetos com JavaScript.

## Conteúdo

### Desafios principais

- **Classificador de nível de herói:** utiliza variáveis, operadores e estruturas condicionais.
- **Calculadora de partidas ranqueadas:** pratica funções, cálculos e classificação por faixas.
- **Classes de um jogo:** aplica classes, objetos, propriedades e métodos em uma interface web simples.

### Desafios de código

O diretório `src/desafiosCodigoDio` reúne exercícios adicionais, incluindo:

- captura e combinação de nomes de Pokémon;
- coleta de tesouros;
- geração de biomas;
- gerenciamento de itens mágicos;
- jornada do herói;
- cálculo de pontos de experiência.

## Tecnologias

- JavaScript
- HTML5
- CSS3

## Estrutura

```text
src/
├── desafioFelipao1/       # classificador de nível
├── desafioFelipao2/       # partidas ranqueadas
├── desafioFelipao3/       # classes de um jogo
└── desafiosCodigoDio/     # exercícios complementares
```

## Como executar

Os exercícios em JavaScript podem ser executados com Node.js:

```bash
node caminho/para/o/arquivo.js
```

Para o desafio com interface web, abra `src/desafioFelipao3/index.html` em um navegador.

## Objetivo

Consolidar conceitos de lógica de programação por meio de problemas pequenos, progressivos e fáceis de revisar.
